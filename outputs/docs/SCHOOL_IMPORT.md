# 东北大学课表导入调查

2026-11-06。已实现东北大学打印 XLSX 的解析、核对预览与批量导入。在线爬取尚未实现；文件导入不等于在线抓取。

## 已知事实

- 用户指定 jwxt.neu.edu.cn，已本人登录「我的课表」，说明「打印」可选 Word／Excel；未取得实际文件，不能确定扩展名、合并单元格、周次和列结构。
- [学校官方通知](https://aao.neu.edu.cn/2026/0227/c9434a450413/page.htm)：启用新版系统，统一身份认证，校外按学校说明使用 WebVPN／OpenVPN。不能沿用旧版解析器作为兼容承诺。
- 本机匿名请求能跳转到 pass.neu.edu.cn/tpass/login，未提交凭据，不记录临时 Cookie。
- [学校公开前端 JS](https://jwxt.neu.edu.cn/jwapp/sys/homeapp/home/umi.3c7a30c3.js)包含学生课表 getMyScheduleDetail.do、节次 getSections.do、校区 getMyScheduledCampus.do 和学期 xnxq.do；参数包含 termCode、campusCode、type、week，代码读取 datas.arrangedList、beginSection／endSection、dayOfWeek。仅静态阅读，未执行代码；这些不证明登录后响应格式、完整学期周次和接口稳定性。
- 浏览器自动化能读取 LifeFlow，本校页的页面树、截图和只读 DOM 均反复超时；标签列表确认登录后为本科教务管理系统。不能推断为网站禁爬或用户登录失败。未重置学校会话，未读取密码或 Cookie。

## 目标流程

选择学校 → 本人在官方页面登录 → 选择学期 → 读取本人课表 → 预览周次、星期、节次、地点及冲突 → 用户确认 → 返回实际导入、重复、冲突统计。

首站只适配实际验证后的东北大学版本；其他学校另行适配。按用户触发读取，不采集同学和成绩，不后台持续爬取。源域名设白名单、请求超时和数量上限，不做任意 URL 后端代理。学校密码、Cookie 不进入 AI、LifeFlow 云端、日志或 Git。

Safari／PWA 受[同源策略](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)限制，打开学校页面不等于能读取其内容或会话。Capacitor [Browser 插件](https://capacitorjs.com/docs/apis/browser)在 iOS 使用 SFSafariViewController，公开接口不能当作任意 DOM 读取接口。原生受控 WebView／本机采集路径须另行实测；当前缺完整 Xcode，不能承诺原生导入已可用。未来云服务器也不自动具备校园网／VPN 连通性。

学校打印导出的 Excel 可用于核对真实格式及离线导入备用；离线文件通路不等于一键在线抓取。需区分 XLSX、XLS、HTML 伪装 Excel，不能猜测列号；不执行公式、宏或外链。

## 文件通路使用方法

1. 在设置中保存实际学期开始日期与节次表。第 1 周按该日期所在的周一至周日计算；东大课程按北京时间 UTC+08 导入。
2. 设置页顶部点「导入课表」，选择教务系统「打印 → Excel」导出的原始 .xlsx（不超过 512KB）。不支持旧 XLS、Word 或任意学校表格。
3. 核对每条记录的星期、周次、地点和起止节。多门课共用单元格时，导出没有逐门节次，原格范围仅供参考；必须修改为真实节次并勾选「已核对节次并选入」。此类记录默认不选。
4. 点击「检查所选记录」，审阅展开后的具体日期和钟点。单门课的多组周次／地点可分别选入；它们是上课记录，不是不同课程数量。
5. 确认导入。相同实例跳过，冲突双方不自动取舍；允许明确勾选仅导入无冲突安排，结果分别报告新增、重复与冲突。已有安排不覆盖。

未排具体节次课程单列，不编造时间。无法识别的周次／字段显示警告并跳过，不能将跳过项称为完成。

## 当前实现和实测

- ExcelJS 仅服务端读取，保留合并结构，不把大解析库装进手机前端。接收原始二进制，不保存原文件、不上传模型。拒绝宏、公式、超链接、过大压缩包及超出行列边界的文件。它不提供所有恶意 Office 文件的完整沙箱；公网发布前仍需独立进程隔离和限流评估。
- 解析预览在服务内存保留 15 分钟，最多 5 份；重启后需重新选择文件。确认参数不能替换已解析的课程内容，只能选条目和核对节次。学期／时段版本变化使旧预览失效。
- /api/imports/neu/preview、/plan、/commit 与普通 API 共享来源／令牌保护。确认前在 SQLite 即时事务中重查冲突和摘要；数据变化时整批拒绝，不能依据过期预览写入。单次最多 200 条规则、3000 次安排。
- SQLite schema v4 增加地点、备注与导入来源键。保留旧日程；旧编辑请求缺少地点／备注时不清空现有值。重复导入依据学期、课程、日期和节次识别；调课／换地点出现冲突时人工处理，不实现自动同步。
- 真实文件：1 个工作表、21 个有课单元格，53 条上课规则（不是 53 门课），展开为 245 次候选；其中 40 条需核对节次，1 门未排具体节次。无解析警告。仅选默认无歧义的 13 条，在隔离测试库规划为 100 次、0 重复、0 冲突；没有确认写入真实课表。
- 人工夹具页面：3 条规则默认选 1 条，预览 2 次并确认导入 2 次；在第 1 周见到对应色块，地点、教师备注保留。原始课表及私人解析结果仅在忽略的 work/，公开测试使用人工数据。
- 41 项自动测试、构建／类型检查、Capacitor 同步通过。iPhone 文件选择器、原生编译、在线抓取尚未验证／未实现。

## 数据质量限制

不能从当前 XLSX 合并单元格精确恢复多门课程各自的起止节次，必须人工核对。仅有文件解析通过不代表 245 次安排已全部正确或已导入。截图、登录本身均不能替代在线采集联调；后续在线适配须获取真实 beginSection／endSection 等结构化字段。
